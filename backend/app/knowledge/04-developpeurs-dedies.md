Offre pour les entreprises françaises et européennes (agences, éditeurs, PME,
startups) qui manquent de développeurs.

Arguments : même langue (français) ; décalage horaire faible avec Paris (+1h en
été, +2h en hiver : Madagascar est en avance) ; coût nettement inférieur à un
recrutement en France ; développeurs qui travaillent avec vos outils (Git,
Jira, Slack…) ; code qui appartient au client ; stack Next.js, React,
React Native, Node.js, Python/FastAPI, PHP/Laravel, Java EE.

Équipe : développeurs permanents, renforcés par des développeurs partenaires
selon le besoin. **Ne jamais annoncer un effectif chiffré.**

Qualification : technologies du projet ; nombre de développeurs ; niveau
attendu ; durée de la mission ; date de démarrage ; mode de travail (régie,
forfait) ; outils et horaires de recouvrement souhaités.

> À COMPLÉTER PAR L'ÉQUIPE : prix journalier, durée minimale, période d'essai.
